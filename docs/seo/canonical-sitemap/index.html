canonical 和 sitemap 要指向同一条网址

更新于 2026-10-08

两份清单不是一回事

canonical 和 sitemap 不一致怎么办？先改到一致，再谈别的。sitemap 是你希望被抓取的网址列表。canonical 写在页面里，声明如果存在带参数、带斜杠或不带斜杠的副本，应该把索引算在哪一条上。

sitemap 里放了 A，页面的 canonical 却指向 B，爬虫会同时收到两个信号。它可能抓 A、索引 B，也可能暂时两边都留着。你能决定的部分，是不要主动给出互相矛盾的网址。

写的时候遵守同一条规则

选定一种形式：有没有 www、是 http 还是 https、目录末尾要不要斜杠。sitemap、canonical、站内链接全部用这一种。

不要把整站的 canonical 都指回首页。那会告诉搜索引擎，这些文章只是首页的副本。每篇文章的 canonical 就是它自己的网址。

怎么核对

打开一篇文章的源代码，复制 canonical。再到 sitemap.xml 里找同一条。两边的协议、主机和路径都相同才算对齐。

站点发布之后，用 Chrome 的谷歌搜索看这篇文章对应的查询，自然结果是否落到这条网址。公司内部排序模型的结果分开记。
