把结论放进 main 里的 article

更新于 2026-10-08

抓下来的不都是正文

搜索引擎怎样识别网页正文？它看到的是完整 HTML，导航、相关链接和页脚都在里面。想让结论被当成这篇的内容，就把结论放进 main 中的 article，标题用 h1，后面紧跟段落。

第一段就回答标题里的问题。把答案藏到很后面，或者只用折叠面板展开后才出现，抽取时更容易只拿到导航文字。

不要用样式把字藏起来

白字、零字号、移出屏幕的段落，人看不见，源代码里却还有。这种文字不是正文。本站的样式表不隐藏文字，读者能看到的和源代码里的是同一篇。

链接如果指向另一篇笔记，锚文字就写那篇的题目，放在文章末尾的相关链接里，不要混进第一段充字数。

怎么确认这一页被读到了

在 Chrome 里打开谷歌，搜索「搜索引擎怎样识别网页正文」，看自然结果指向的是不是这篇的网址。公司排序模型对同一批 URL 的排序，用你们自己的打分导出，不由这个静态站计算。
