面包屑 JSON-LD 要和页面上的路径一致

更新于 2026-10-08

机器读的是你写进脚本的那一段

面包屑 JSON-LD 怎么写，取决于页面上已经能看见的那条路径。用 BreadcrumbList，itemListElement 按从首页到当前页的顺序排列。position 从 1 开始，每一项都有名字和网址，最后一项是这一页自己。

看不见的路径不要写进 JSON-LD。页面顶部如果是「首页 / 笔记 / 当前标题」，脚本里也应当是这三步，名字和链接都对得上。

它不能代替正文

结构化数据是正文的旁注。把结论只写进 JSON-LD、正文留空，读者和抽取正文的系统都得不到这篇文章。先把段落写在 article 里，再附上同顺序的面包屑。

本站每一篇笔记都按这个顺序生成：首页，然后是当前这篇。可以查看源代码里的 application/ld+json，对照页面上方的链接。

发布后看结果页，而不是看本地分数

本地生成成功，只说明标记没有写错。是否出现在搜索结果里，用 Chrome 打开谷歌，搜索「面包屑 JSON-LD 怎么写」，数自然结果的位置。公司排序模型如果会吃进这些页面，名次在模型那边看。
