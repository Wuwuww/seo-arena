南门单车

南门单车修理胎压、补胎和气嘴。下面每页只回答一个到店前会问的问题。

  • 自行车胎压打到多少

    按外胎侧壁的区间充气，公路车和山地车分开看。公路车窄胎通常比山地车高一截。体重较重时取区间上沿，雨天取中段，避免胎压顶满后碾到坑洼直接爆胎。

  • 自行车内胎补好能骑多久

    冷补丁压实后可以继续骑，鼓包或第二次漏气就换内胎。补丁边缘如果翘起，充气后会在几公里内再次漏完。蛇咬造成的双孔不适合只补一个眼，内胎该换。

  • 自行车气嘴是美嘴还是法嘴

    两种气嘴都能打，先看气嘴根部再选转接头。美嘴较粗，法嘴较细，还常带一颗小锁母。打气前把锁母拧松，打完再拧回，否则气筒夹不紧。

  • 自行车蛇咬是什么

    内胎上并排两个小孔，多半是胎压过低后轮圈夹到内胎。只补其中一个孔还会漏。先确认轮圈胶带没有移位，再换内胎或把两个孔都补上，并把胎压打回侧壁区间。
