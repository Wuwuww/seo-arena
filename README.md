# seo-arena

一个只有合成网页的搜索攻防沙盘。攻击方改页面和链接，防守方在同一批页面上调排序惩罚。没有爬虫，也不碰线上搜索引擎。

做网页搜索的人平时要对付的，就是这种事：有人用关键词和链接把页面抬上去，排序得把真正回答问题的页面留在前面。

## 这套网页

六条查询，每条有两篇人工标成相关的正文，外加只沾到一个词的干扰页。排序是 BM25 加 PageRank。干净网页上，相关页的 MRR 是 1.00，前五名里没有垃圾页。

训练查询四条，测试查询两条。攻击方只在训练查询上选打法，防守方只在训练查询上选惩罚系数，测试查询不参与选择。

## 攻击

四种打法，都只改这份沙盘网页：

| 打法 | 测试集 spam@5 | 测试集相关 MRR |
| --- | --- | --- |
| 不攻击 | 0.00 | 1.00 |
| 关键词重复 | 0.20 | 1.00 |
| 短页链接农场 | 0.50 | 0.50 |
| 近重复门页 | 0.70 | 1.00 |
| 三种一起上 | 0.80 | 0.20 |

关键词重复挤进前五，但拿不走第一名。BM25 对词频有饱和，重复到后面加分有限。链接农场能把第一名抢走。门页会占掉前五的位置，第一条相关结果还在。三种叠在一起，第一名才掉到后面，spam@5 到 0.80，相关 MRR 掉到 0.20。攻击方因此选了组合打法。

## 防守

惩罚只用页面自己算得出来的三样东西，不用「这是垃圾页」这个标签：

- 正文里不同词太少，说明在重复堆词
- 一条页面的入链大多来自极短页面，或者它自己只指向这种短页
- 和另一篇长度接近的页面，词集合几乎重合

防守方在系数网格里选一组，要求训练查询上的相关 MRR 不低于干净网页的 85%，再尽量把 spam@5 压下去。这次选中的是链接农场 0.8、近重复 3.2，重复堆词系数为 0。近重复已经盖住了那些抄出来的门页，堆词惩罚没有额外收益。

测试集上，spam@5 从 0.80 回到 0.00，相关 MRR 从 0.20 回到 1.00。

## 运行

```bash
cd seo-arena
PYTHONPATH=src python -m seo_arena
PYTHONPATH=src python -m pytest -q
```

结果写到 `runs/arena.json`。

## 不要这样讲

不要说这个沙盘能打过百度、谷歌或任何线上排序。网页、链接和标签都是手写的。它说明的是：词频饱和之后，真正把相关结果顶下去的是链接和近重复；这两件事可以用无标签特征压回去，而且压的时候不必牺牲第一条相关结果。
